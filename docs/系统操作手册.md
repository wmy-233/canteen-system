## 3. 功能操作步骤
### 3.1 管理员演示
登录 → 用户管理 → 档口审核 → 全局统计图表。
### 3.2 商家演示
登录 → 新增菜品（设每日限量）→ 出餐看板 → 销量图表。
### 3.3 学生完整点餐流程
登录 → 浏览菜品 → 加购 → 下单支付 →（自取单）查看取餐码 /（配送单）等待骑手送达 → 评价。

### 3.4 校园配送员演示
登录页选「校园配送端」→ 用 `rider1 / 123456` 登录 → 接单大厅抢单 → 我的跑腿单「标记送达」。
（学生下单时选「配送」即产生待接单；管理员端「配送调度」也可直接指派/兜底送达）

## 4. 常见问题
- Q: Redis 连接失败？A: 检查本地 Redis 服务是否启动（redis-server.exe）。
- Q: 登录 401？A: token 过期，重新登录。
