## 1. 环境准备（演示前 5 分钟）

```bash
# 1) 起 Docker 容器（首次会自动建库并执行 schema.sql + init_data.sql）
docker compose up -d

# 2) 验证
docker exec canteen-redis redis-cli ping                       # PONG
docker exec canteen-mysql mysql -uroot -p123456 -e "SELECT 1"  # 1

# 3) 首次初始化需按顺序执行三个补丁（patch_rider.sql 不可重复执行）
docker exec -i canteen-mysql mysql -uroot -p123456 canteen < sql/patch_message_complaint.sql
docker exec -i canteen-mysql mysql -uroot -p123456 canteen < sql/patch_rider.sql
docker exec -i canteen-mysql mysql -uroot -p123456 canteen < sql/patch_enhancements.sql

# 4) 后端 / 前端
cd backend  && mvn spring-boot:run        # http://localhost:8080/doc.html
cd frontend && npm install && npm run dev # http://localhost:5173
```

> 想重置演示数据：`docker compose down -v && docker compose up -d`，然后**重新执行三个补丁**（补表与配送演示数据）。

## 3. 学生端演示（主线：自取）

1. **登录**：`student / 123456` → 进入学生端首页，观察余额卡片、进行中订单、优惠券数、实时热销榜 Top8。
2. **浏览点餐**：「菜品浏览」→ 切换食堂/档口/分类、搜索关键字；找限量菜（红烧排骨等）看「仅剩 N 份 / 今日剩 N 份 / 已售罄」标签。
3. **加购**：点菜品卡「＋加购」；可继续加其他档口菜品，购物车按档口分组并显示小计。
4. **下单**：购物车底部「去结算」→ 用餐方式选**自取** → 选券（自动最优）→ 确认下单 → 成功页展示**大号 4 位取餐码**与订单号。
5. **出示二维码**：「我的订单」→ 待处理单「出示二维码」→ 显示 5 分钟有效的动态码与倒计时（过期自动刷新）。
6. **核销后评价**：商家核销后，本单出现「评价」→ 对菜品打 1–5 分 + 文字提交。
7. **钱包/优惠券**：「我的钱包」充值（快捷金额或自定义）→ 看流水；「优惠券」领取新券。
8. **投诉**：「我的订单」→ 已完成单「投诉」→ 选类型（质量/漏发/配送/态度）+ 填内容提交；「我的投诉」可看商家回应与管理员裁定/退款。
9. **AI 助手**：右下角悬浮「胆子肥嘟嘟」→ 点开 → 试「推荐点啥？」「💰 查余额」「📜 查订单」；配置 Key 后可问「帮我加一份宫保鸡丁」，回复中菜品卡片点「去加购」。

### 3.1 学生端演示（新增：校内配送）

1. 同样加购后进入结算，用餐方式选 **校内配送（+¥2 跑腿费）**。
2. **送达地点**下拉选择「宿舍楼 / 图书馆 / 第一教学楼 / …」，并可直接输入具体楼栋/房间（如「3 栋 502」）——必填，否则确认按钮禁用。
3. 观察金额明细：菜品小计 − 优惠 + 跑腿费（券不抵扣跑腿费）；提示「送达后结算给校园配送员」。
4. 下单成功页配送单**没有取餐码**（显示 🛵），订单列表显示送达地点、跑腿费、配送状态「待分配」。
5. 配送员抢单后状态变「配送中·王小跑」，送达后变「已送达」，学生收到站内消息。

## 4. 商家端演示

1. **登录**：`merchant / 123456`。
2. **菜品管理**：「菜品管理」→ 新增菜品（名称/分类/价格/日限量；日限量 >0 即限量菜）→ 上架 → 学生端立即可见；试上下架开关与编辑。
3. **出餐看板**：「出餐看板」→ 待处理队列显示大号取餐码；开「🔊 新订单语音播报」，学生下新单后约 15 秒语音提示。
4. **扫码核销**：待处理自取单点「扫码核销 · 出餐」→ 扫码枪扫学生二维码，或手工粘贴 `CANTEEN|订单号|取餐码|过期时间戳` → 校验通过后订单变「已完成」，学生可评价。
   - 配送单在此只显示「等待配送员接单（跑腿大厅）」，不可核销。
5. **销量统计**：「销量统计」→ 切换 7/14/30 天看营业额折线 + 订单柱图、菜品销量排行。
6. **投诉处理**：「投诉处理」→ 对待回应投诉点「提交回应」；已裁定单可看管理员结果与退款额。
7. **消息中心**：右上角铃铛查看未读通知，点开标记已读。

## 5. 校园配送端演示

1. **登录**：`rider1 / 123456` → 进入「跑腿大厅」，标题说明勤工助学配送场景。
2. **抢单**：「🍱 可抢订单」列表显示待接单：订单号、档口、菜品实付、**跑腿费 ¥2**、送达地点、时间。点「接这单」→ 确认。
   - 并发演示：用两个浏览器分别以 `rider1`/另一在岗配送员抢同一单，只有一人成功，另一人提示「手慢了，该单可能已被其他配送员接走」。
3. **我的配送**：「我的配送」→ 配送中订单点「标记送达」→ 确认 → 状态变「已送达」，跑腿费结算进钱包。配送员端没有独立钱包页：在管理端「用户管理」查看 `rider1` 余额变化，或在数据库 `wallet_record` 表查看 `type=4`「跑腿收入」流水。
4. **停用演示**：用 `rider2 / 123456` 登录应被拒（账号停用）；管理员在配送调度页把 `rider2` 切到在岗后可登录抢单。

## 6. 管理端演示

1. **登录**：`admin / 123456` → 总览首页看 6 个 KPI（累计/今日营业额与订单、用户数、营业档口）、7 日趋势图、全平台热销 Top。
2. **用户管理**：「用户管理」→ 搜索 → 禁用某学生后该账号再登录应被拒；「改角色」可把账号改为 STUDENT/MERCHANT/RIDER（自己账号被保护，不能改）。
3. **档口审核**：「档口审核」→ 待审核 tab 里有「麻辣香锅」→ 点「✓通过入驻」→ 学生端菜品浏览可见该档口菜品；驳回则维持停业。
4. **配送调度**：「配送调度」→ 右侧「待分配配送单」选在岗配送员 → 指派；也可在此新建配送员账号（账号/密码/姓名/电话）。
5. **投诉管理**：「投诉管理」→ 商家超时未回应单带「⚠️ 已超时升级」标记；点「标记超时升级」手动触发；点「裁定」→ 选成立/不成立 → 勾选退款 → 填裁定说明 → 提交，学生余额与券/库存按规则回滚。
6. **优惠券管理**：「优惠券管理」→ 新建发放（券名/门槛/面额/库存/到期时间）→ 列表中看剩余库存。
7. **操作日志**：「操作日志」→ 按操作人/模块/结果筛选，查看关键操作的方法、参数、耗时与成败；可清空（有二次确认）。
8. **全局统计 / 消息中心**：「全局统计」看档口排行与趋势；右上角铃铛看系统通知。

## 7. 亮点串联演示（推荐顺序，约 10 分钟）

| 序 | 操作 | 看点 |
|---|---|---|
| 1 | 学生端并发给限量菜下单（或压测脚本） | 三重防超卖，成功数=库存，终值 0 |
| 2 | 购物车加两个档口菜品一次结算 | 跨档口原子拆单（`batch_no`），全部成功或全回滚 |
| 3 | 学生选配送 + 填「图书馆 3 楼」下单 → `rider1` 抢单 → 送达 | 担保交易、抢单锁、`type=4` 结算 |
| 4 | 投诉不成立/成立勾选退款 | 余额+券+库存+销量+Redis 全量回滚，防重复退款 |
| 5 | 商家 24h 未回应 → 自动/手动升级 → 管理员裁定 | 定时任务 + 站内消息 + 状态机 |
| 6 | 管理端「操作日志」筛选刚才操作 | AOP 落库留痕 |
| 7 | AI 助手查余额/查订单/加购 | DeepSeek Function Calling（无 Key 演示本地兜底） |
| 8 | 学生二维码 → 商家扫码核销 + 语音播报 | 动态码与语音 |
| 9 | 关闭 Docker（Redis 停）后重做下单 | 降级模式主流程照常 |

## 8. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| Redis 连不上 / 后端报 Redisson 失败 | Docker Desktop 没开或原生 Redis 占 6379；先 `net stop Redis`，再 `docker compose up -d`；Redis 关着也能跑主流程（降级） |
| MySQL 1045 / 10061 | 密码须 `123456`；容器未起则 `docker compose up -d`；本机旧 MySQL 占 3306 先停用 |
| 登录后跳错页面 / 空白页 | 清浏览器 localStorage 的 `token`/`role` 重新登录；portal 只是主题，按真实角色跳转 |
| 401 | token 过期/被禁用/角色变更 → 重新登录 |
| 403 | 用错角色账号（如学生访问管理端接口） |
| 配送功能报「表不存在」 | 三个补丁没按序执行；见第 1 节，且 `patch_rider.sql` 只需一次 |
| 抢单提示「手慢了」 | 并发下另一配送员已抢到，属正常业务提示 |
| 二维码已过期 | 5 分钟 TTL，等页面自动刷新后再出示 |
| 语音不响 | 浏览器需用户交互后才允许播放；检查是否静音、是否点了「播报：关」 |
| AI 回答很机械 | 未配 `VITE_DEEPSEEK_API_KEY`，走本地关键词兜底；配置后需重启前端 |
| 中文乱码 | 连接工具编码改 UTF-8；库内 utf8mb4 正常 |
| 想恢复初始数据 | `docker compose down -v && docker compose up -d` 后重跑三个补丁；会清除注册用户 |
