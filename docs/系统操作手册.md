### 2.3 登录、退出与切换账号

| 1 | 打开登录页，选择角色 portal | 显示对应主题的登录界面 | portal 仅为界面主题，不参与鉴权 |

### 2.4 登录常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 登录后跳错页面或空白页 | 清除浏览器本地存储中的 token/role 后重新登录 |
| 提示未登录（401） | 凭证过期、账号被禁用或角色变更，重新登录 |
| 提示无权限（403） | 用错角色账号（如学生访问管理端功能） |

## 7. 异常处理与常见问题

### 7.1 按错误码索引

| 错误码 | 含义 | 处理 |
|---|---|---|
| 400 | 参数或状态非法 | 检查输入与订单状态 |
| 401 | 未登录或凭证无效 | 重新登录 |
| 403 | 无权限 | 换用对应角色账号 |
| 500 | 系统异常 | 查看日志（R-09） |

### 7.2 按现象索引

| 现象 | 原因 / 处理 |
|---|---|
| Redis 连不上 / 后端报连接失败 | Docker Desktop 未启动或原生 Redis 占用 6379 端口；先停止原生服务，再启动容器；Redis 不可用时主流程仍可用（降级模式） |
| MySQL 1045 / 10061 | 密码须为 `123456`；容器未启动则执行 `docker compose up -d`；本机旧 MySQL 占用 3306 端口须先停用 |
| 配送功能报“表不存在” | 三个增量脚本未按序执行；见附录 A，且 `patch_rider.sql` 只需执行一次 |
| 抢单提示“该订单已被其他配送员抢接” | 为预期业务提示，说明已被他人抢到 |
| 二维码已过期 | 5 分钟有效期，等待页面自动刷新后再出示 |
| 语音不响 | 浏览器需用户交互后才允许播放；检查是否静音或点了“播报：关” |
| AI 回答机械 | 未配置 AI 密钥，启用本地关键词应答（降级）；配置后需重启前端 |
| 中文显示乱码 | 连接工具编码改为 UTF-8；库内数据为 utf8mb4 正常 |
| Redis 服务恢复后功能未恢复 | 当前仅在后端启动时探测缓存服务，恢复后需重启后端（R-04） |
